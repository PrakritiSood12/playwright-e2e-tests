# Instructions and Notes

**Setup Git Repo**
1. Git Commands
- git init
- git status
- git add
- git commit -m "<commit-message>"
- git branch -M main
- git remote -v
- git remote add origin <repo-url>
- git push -u origin main
- git push -f origin main
